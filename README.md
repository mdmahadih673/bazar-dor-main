# 🥬 Bazar Dor — বাজার দর

### Your Daily Fresh Vegetable Market 🛒

Bazar Dor is a vegetable market website designed to make everyday shopping easier. It provides a simple and user-friendly platform where users can explore a digital vegetable market with a clean interface and a fresh green-themed design.

🔗 **Live Website:** https://bazar-dor-main.vercel.app/  
📂 **GitHub Repository:** https://github.com/mdmahadih673/bazar-dor-main

---

## ✨ Features

- 🥦 **Fresh Market Theme** — A clean, modern interface inspired by fresh vegetables and local markets.
- 📱 **Responsive Design** — Designed to provide a smooth experience across different screen sizes.
- 🔐 **Authentication** — User authentication powered by Better Auth.
- 👤 **User Account** — Authentication-focused user experience.
- 🌿 **Green UI Design** — A fresh visual identity with a green color palette.
- ⚡ **Modern Web Technologies** — Built with Next.js and TypeScript.
- 🚀 **Live Deployment** — Deployed on Vercel.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/mdmahadih673/bazar-dor-main.git
```

### 2. Navigate to the project directory

```bash
cd bazar-dor-main
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the project root and add the required environment variables for authentication and database connectivity.

Example:

```env
BETTER_AUTH_SECRET=your_secret_key
BETTER_AUTH_URL=http://localhost:3000
BETTER_AUTH_MONGODB_URL=your_mongodb_connection_string
```

Add any other variables required by your project configuration. Keep all secrets private and never commit your `.env` file to GitHub.

### 5. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
